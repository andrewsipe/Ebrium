Flag reference

There is one plan. These are the ways to run it.
ebrium fonts/ -rOne centered line box per family. You confirm before anything is written.
-nPreview. Nothing is written.
-ySkip the confirmation.
--span %Letter-span floor (default 130). Tighter 120, looser 150.
--line-gap %Extra space between lines (default 0). 5 is slightly looser.
--no-clusterOne box from the family's outline extremes, so nothing clips.
--match "Family A,Family B"Pair family names that do not already group, so they share one line box. Repeat the flag for another pair.
ebrium probe fonts/ -rRead the metrics. Write nothing.

Effect cuts inherit the family box. Caption, Display, Subhead, and Small Text each keep their own. A review at the end names anything worth a look, including how much the line box would have moved if a script or effect cut had stayed in the core. The box is 130% of the em at minimum, capitals centered, with room for a real accent or descender.
