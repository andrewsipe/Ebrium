Flag reference

Each subcommand only defines flags that do something for it. Invalid combinations are argparse errors, not silent warnings. Live wording: ebrium <subcommand> --help.

Who gets what

Subcommand Beyond shared input / preview / spacing / detection
individual No clustering or report flags; no --max-adjustment
family --no-cluster, --merge, --ignore-term, --line-box*, --max-adjustment
superfamily Same as family except --no-cluster; plus --exclude
probe Read-only metrics tables grouped by family. --superfamily, --merge, --ignore-term, --exclude, -q, -o.
Variable fonts. family, individual, and superfamily rewrite the default instance only and leave MVAR and HVAR alone. probe records that default instance with the rest of the family and does not write.

Shared (individual / family / superfamily)

FlagMeaning
PATH…Font files or directories (default: current directory)
-r, --recursiveRecurse into directories
--use-ttxAlso process .ttx files
-n, --dry-runPreview without writing
-y, --yesSkip confirmation prompt
-l, --letter-height %Letter-span floor (default 130); auto-adjust may raise it
-t, --top-margin %Headroom above caps (default 25); may be ignored if already clear
--no-auto-adjustUse exact --letter-height
-a, --assume TYPE:PATTERNForce classify: script, decorative, unicase, uniwidth (repeatable)
--exclude-measuring PATTERNExclude from family calculations (not a classify flag)
-v / -vvOn probe, -v adds a compact hhea / typo / Win table. -vv prints one wide table with each of those values in its own column.

probe only

FlagMeaning
-q, --quiet Current filename and a progress bar, then a count. The metrics go to -o. Cannot be combined with -v.
-o, --output FILE Tab-separated sheet, one row per font. hhea, typo, and Win values are separate columns. A relative file is saved at the top of the directory you probed.
-v -v adds the compact hhea / typo / Win table. -vv prints one wide table with each value in its own column.

family only

FlagMeaning
--no-cluster Skip clustering; bbox extremes for every font. For unpredictable or mis-detected metrics. Default is to cluster. Formerly --safe-max.

family and superfamily

FlagMeaning
--max-adjustment %Cap how far family extremes may pull a font
-m, --merge "A,B" One complete group per flag. Repeat --merge for separate groups. -m A -m B does not merge A with B. Formerly -c / --combine.
-i, --ignore-term TERM Drop a whole word from family names before grouping (case-sensitive, anywhere; repeatable or comma-separated)
-e, --exclude FAMILYsuperfamily only — keep a family out of the merge
-b, --line-box MODE auto | force-baseline | force-baseline-main-cluster | safe-hhea
--line-box-from PATH_OR_GLOB Pin reference font; implies force-baseline if mode left at auto
Abbreviation trap. Parsers set allow_abbrev=False, so --exclude under individual errors instead of silently matching --exclude-measuring.
Exit codes. 0 done; 1 no font files; 2 no measurable fonts, or bad arguments; 3 aborted at the prompt. probe only uses 0, 1, and 2.

Recipes

# Preview family plan
ebrium family fonts/ -r -n

# Unpredictable metrics: skip clustering
ebrium family fonts/ -r --no-cluster

# Force two families into one group before clustering
ebrium family fonts/ -r --merge "Display,DisplayAlt"

# Unify line box from the main optical cluster
ebrium family fonts/ -r -b force-baseline-main-cluster

# Superfamily, leave one family alone
ebrium superfamily fonts/ -r -e "SpecialSans"
