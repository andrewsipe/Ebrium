Pipeline

How it thinks

One command. Fonts are grouped by family name.

  1. Measure Cap height, x-height, ascenders, descenders, the tallest accented capital, and glyph bounds — normalized by each font’s UPM.
  2. Separate Core styles set the line box. Effect and script cuts inherit it. Caption, Display, Subhead, and Small Text each get their own box. A layered or color stack copies one box across its files. --no-cluster uses outline extremes instead.
  3. Plan Center capitals in the line box and grow to the span floor (--span, default 130) while staying centered. Raise a side only when a measured accent or descender needs it. The line gap is 0 unless --line-gap says otherwise. Win is the outline extremes plus 2%. See Concepts.
  4. Apply Write metrics in place (unless -n). Enable USE_TYPO_METRICS when OS/2 ≥ 4. probe does not write.

Variable fonts

Default instance only. A normal run reads and writes the default instance the same way it treats a static font. It does not rewrite MVAR or HVAR. probe reads that same default instance and does not write.

What stays untouched

  • unitsPerEm
  • Glyph outlines and advances
  • Name tables (use FontNameID for those)
Exit codes. 0 done (including dry-run / nothing to change); 1 no font files; 2 no measurable fonts or bad args; 3 aborted at confirmation. probe only uses 0 / 1 / 2.
