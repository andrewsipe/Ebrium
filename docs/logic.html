Pipeline

How it thinks

The subcommand picks the grouping strategy. Everything after that follows the same four stages.

  1. Measure Cap height (optical), x-height, ascenders, descenders, glyph bounds — normalized by each font’s UPM so mixed masters compare fairly.
  2. Cluster Optically identical styles share a core plan. Outliers (decorative / script span, mis-detected metrics) can sit outside the main cluster. Skipped entirely under individual and under family --no-cluster.
  3. Plan Build typo/hhea for the core cluster; set Win from family extremes; optionally unify the line box (--line-box); apply letter-height / top-margin floors and --max-adjustment caps.
  4. Apply Write metrics in place (unless -n). Enable USE_TYPO_METRICS when OS/2 ≥ 4. Zero line gaps. probe does not write.

Grouping strategies

SubcommandGroupingClustering
individual None — one font at a time No
family By family name Yes (default); off with --no-cluster
superfamily Merge families sharing a name prefix Yes, across the merge
probe — Read-only metrics tables; no write

Line box modes

Under family / superfamily, --line-box controls typo/hhea unification (Win still uses max ranges where that mode says so):

ModeBehavior
autoEach font keeps its own planned typo/hhea (default)
force-baselineUnify using the family’s largest-span style
force-baseline-main-clusterSame, but reference comes only from the largest optical cluster
safe-hheaAverage existing typo/hhea across the family; apply uniformly

--line-box-from PATH_OR_GLOB pins the reference font and implies force-baseline if you left the mode at auto. Single-font “families” skip force-baseline (nothing to unify).

Variable fonts

Default instance only. family, individual, and superfamily read and write the default instance the same way they treat a static font. They do not rewrite MVAR or HVAR. probe reads that same default instance and does not write.

What stays untouched

  • unitsPerEm
  • Glyph outlines and advances
  • Name tables (use FontNameID for those)
Exit codes. 0 done (including dry-run / nothing to change); 1 no font files; 2 no measurable fonts or bad args; 3 aborted at confirmation. probe only uses 0 / 1 / 2.
