Four modes from one baseline

Normalization is about stacked readable text — not a single display line. At 0 line-gap, typo/hhea boxes abut; ink that sticks past typo collides into the neighboring line. Small sizes hide that; the zoom panel makes it visible.

Baseline

All 19 styles: typo 980/−280 (span 1260), Win 1210/530, cap 706. Black’s ink fills that Win box; Thin sits inside it. Name ID 16: Register (statics) / Register Variable (VF).

What sits in each band

“Ink” = the actual glyph outlines (the dashed grey box). Example numbers: Black under individual — typo 1028/−298, bbox 1210/−530, Win 1234/541.

  1. Cap body (baseline → cap). The capital letters live here. Always inside typo.
  2. Line-box headroom (cap → typo top). Counted in leading. May hold accents (É) or be empty air — either way it widens line spacing.
  3. Overhang (typo top → ink top). Real ink outside the line box. Still drawn. Does not add leading — it collides into the previous line’s slot. Same story below for descenders.
  4. Clip buffer (ink top → Win top). Usually empty. Keeps Windows from clipping. If ink ever passes Win, that’s the clip risk.

Collision risk = ink past typo.
Clip risk = ink past Win.
