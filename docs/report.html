probe

Reading probe

ebrium probe prints read-only metrics, one group at a time. Nothing is written to the fonts. The driver — the font with the tallest measured ascenders — is the magenta filename and the first row. The other rows run from the smallest pull to the largest.

Default

Fits a half-width terminal. Cap height and x-height are measured from the outlines. Shift is the clustered family plan. No cluster is the same comparison with clustering off. --superfamily shows only the clustered pull. -v restores the shorter names (UPM, Cap, xHt, Pull) and the unit counts.

Sans — 3 fonts — driver Sans-Black.ttf File Cap height x-height Shift Sans-Black.ttf 710 500 0% Sans-Bold.ttf 705 490 6.5% ↑ Sans-Regular.ttf 700 480 8.5% ↑

-v

Adds a second table. A/D/L is ascender, descender, and line gap, in that order. Win is ascent and descent only. These are the values stored in the font now.

File hhea A/D/L sTypo A/D/L usWin A/D UseTypo Sans-Black.ttf 820/-205/0 820/-205/0 840/210 set Sans-Bold.ttf 800/-200/0 800/-200/0 820/205 set

-vv

One wide table. The same numbers as -v, each in its own column: hheaA hheaD hheaLG, sTypoA sTypoD sTypoLG, and WinA WinD, plus units per em, cap height, x-height, UseTypo, and pull.

Column names

In the terminalFull nameWhat it is
UPM units per em The em square, in font units, from the head table. The other numbers on the row are in these units. ebrium does not change it.
Cap cap height Measured height of the capitals, from the baseline, in font units. The stored OS/2 field for this is sCapHeight. This column is the measurement, not that field.
xHt x-height Measured height of the lowercase, from the baseline, in font units. The stored OS/2 field for this is sxHeight. This column is the measurement, not that field.
Shift (default), Pull (-v) family pull How far sharing the family plan would move this font’s ascender compared with measuring the font alone. The default shows a percent and an arrow. -v adds the unit count, such as +70u (+8.5%). The driver is 0%.
hhea A/D/L
hheaA hheaD hheaLG		 hhea ascent, descent, line gap The line box stored in the hhea table. A is ascent (above the baseline). D is descent (below the baseline, stored as a negative number). L and LG are the line gap, extra space between lines. In the compact table the three numbers share one cell, in that order.
sTypo A/D/L
sTypoA sTypoD sTypoLG		 sTypoAscender, sTypoDescender, sTypoLineGap The typographic line box stored in the OS/2 table. Same three roles as hhea: above the baseline, below the baseline, and the gap between lines. Apps that honor USE_TYPO_METRICS use this box for line spacing.
usWin A/D
WinA WinD		 usWinAscent, usWinDescent The clipping box stored in the OS/2 table. Ascent is how far above the baseline letters may draw before an app may chop them. Descent is how far below. There is no Win line gap.
UseTypo USE_TYPO_METRICS Bit 7 of OS/2 fsSelection. set means the typo line box is the one apps should use for line spacing. clear means that bit is off. OS/2 version 4 or newer is required for the bit to exist.

Sliders

Printed under the group, one block per variable font. The axes, whether line spacing stays the same, and whether a slider end passes the clipping box, as a percent of the em. A small percent is a hairline at reading size. Static fonts have no block.

Spreadsheet

-o probe.tsv writes one row per font, with every hhea, typo, and Win value in its own column, plus the slider note. A relative path is saved at the top of the folder you probed. -q keeps the terminal to a progress bar and the count.

What to do next

  • Pulls look fine — run family with -n first, then -y if you’re ready.
  • One style is dragged hard — process it with individual, or group it differently.
  • Names grouped wrong — probe --ignore-term, --merge, or --superfamily / --exclude.
Not the same as the change preview. A normal run lists the metric writes. Reading a run walks through that printout. probe compares family vs solo ascender impact and does not write.
