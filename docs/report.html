--report

Report lookup

ebrium family … --report (or superfamily) prints a dry-run impact analysis: how much each style’s planned ascender differs from what it would get alone. Implies -n — nothing is written to the fonts (a checkpoint file may still be written).

Sample shape

Family Normalization Impact Report Font Sans (3 fonts) Family ascender: 0.8200 (normalized) Driven by: Sans-Black.ttf (asc: 820) ↑ Sans-Regular.ttf + 70 units (+8.5%) - pulled up by family ↑ Sans-Bold.ttf + 50 units (+6.5%) - pulled up by family ✓ Sans-Black.ttf ± 0 units (+0.0%) - minimal impact High normalization impact detected (8.5% max adjustment) Consider the individual subcommand for heavily affected fonts Or use --max-adjustment 6.8 to limit adjustment

Line by line

You seeIt means
Family ascender: N (normalized) Family-wide planned ascender as a fraction of UPM (same plan, scaled per font later).
Driven by: file (asc: …) The font with the tallest measured ascenders. The planned family ascender can still come from cap height plus headroom, rather than that font’s ascender alone.
↑ … pulled up by family This font’s solo plan is shorter; sharing the family plan raises its ascender (units and %).
↓ … pulled down by family Rare: family plan is shorter than the font’s solo plan.
✓ … minimal impact Absolute change under ~1% — effectively the driver or already aligned.
High normalization impact… Max |pull| over 8%. Suggestions: run individual for outliers, or lower --max-adjustment.
Uniwidth families Summary of families flagged as fixed-advance; normalization reinforces that intent.
single-font families skipped No pull analysis when the group has one font — there is no second style to compare. The font is still normalized on a normal run.

What to do next

  • Pulls look fine — drop --report and run with -y if you’re ready, or leave the prompt on.
  • One style is dragged hard — process it with individual, or exclude it from measuring / group it differently.
  • Whole family too aggressive — tighten --max-adjustment, or inspect clustering with/without --no-cluster.
  • Names grouped wrong — --ignore-term, --merge, or switch to superfamily / --exclude.
Not the same as the change preview. A normal run lists the metric writes. Reading a run walks through that printout. --report compares family vs solo ascender impact. Use both when diagnosing a surprising plan.
