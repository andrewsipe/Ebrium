Vocabulary

Concepts

Terms you’ll see in the CLI, the report, and the planned metrics. Skim once; come back when a flag name stops making sense.

Cap height (optical)

The measured height of capital letters used as the stable anchor for clustering. Styles that share an optical size should share cap height even when x-height drifts (optical sizes) or names differ. Clustering always prefers optical cap measurement over table values that may be wrong or stale.

Cluster

A set of fonts treated as optically identical: same planned typo/hhea after normalization (scaled per UPM). Cap height is primary; x-height and descenders are checked more loosely; a large overall bbox span ratio can keep two fonts out of the same cluster (scripts / decorative faces).

Under family, clustering is the default. --safe-max skips it and uses bbox extremes for every font — an advanced opt-out when metrics are unpredictable or mis-detected.

Typo / hhea vs Win

  • typoAscender / typoDescender / typoLineGap (OS/2) and matching hhea values define the line box many apps use when USE_TYPO_METRICS is on (OS/2 v4+).
  • usWinAscent / usWinDescent are clipping bounds. Family-wide Win uses normalized extremes so nothing clips; decorative outliers can expand Win while still inheriting typo from the core cluster.
  • Line gaps are set to zero across typo and hhea.

Letter height & top margin

--letter-height (default 130% of UPM) is a floor for the letter span when auto-adjust is on — large x-heights may raise it. --top-margin (default 25%) asks for headroom above capitals; it can be ignored when actual ascenders already clear it. Use --no-auto-adjust for exactly the percentages you typed.

Family pull

When several fonts share a family plan, a style with smaller solo ascenders can be pulled up toward the family driver. That’s intentional for a shared line box. --report quantifies it; --max-adjustment caps it; individual avoids it entirely.

Detection labels

Filename (or measurement) heuristics can mark fonts as script, decorative, unicase, or uniwidth. Override with -a/--assume TYPE:PATTERN. --exclude-measuring keeps a font out of family calculations without classifying it — different job, different flag.

Superfamily

Families whose names share a prefix can be merged into one planning unit (superfamily). Use --exclude to keep a family out of that merge, and --combine / --ignore-term when names don’t group the way you want.

Checkpoint

Every measuring run (including -n / --report) writes .metrics_checkpoint.json in the current working directory. It caches measurements and clusters and resets when options or the font set change. probe never measures, so it never writes one.
