Vocabulary

Concepts

Terms you’ll see in the CLI, the report, and the planned metrics. Skim once; come back when a flag name stops making sense.

Cap height (optical)

The measured height of capital letters used as the stable anchor for clustering. Styles that share an optical size should share cap height even when x-height drifts (optical sizes) or names differ. Clustering always prefers optical cap measurement over table values that may be wrong or stale.

Cluster

A set of fonts treated as optically identical: same planned typo/hhea after normalization (scaled per UPM). Cap height is primary; x-height and descenders are checked more loosely; a large overall bbox span ratio can keep two fonts out of the same cluster (scripts / decorative faces).

Under family, clustering is the default. --no-cluster skips it and uses bbox extremes for every font — for metrics that are unpredictable or mis-detected.

Typo / hhea vs Win

A default run makes the line box at least 130% of the em — 1300 units when the em is 1000 — and sets the line gap to 0. Baseline to baseline is then 1300. The before picture is a file that has not been through that run. The letters stay the same size, and the em stays 1000.

  • typoAscender / typoDescender / typoLineGap (OS/2) and matching hhea values define the line box many apps use when USE_TYPO_METRICS is on (OS/2 v4+).
  • usWinAscent / usWinDescent are clipping bounds. Family-wide Win uses normalized extremes so nothing clips; decorative outliers can expand Win while still inheriting typo from the core cluster.
  • Line gaps are set to zero across typo and hhea.

Letter height & top margin

--letter-height (default 130% of UPM) is a floor for the letter span when auto-adjust is on — large x-heights may raise it. --top-margin (default 25%) asks for headroom above capitals; it can be ignored when actual ascenders already clear it. Use --no-auto-adjust for exactly the percentages you typed.

Family pull

When several fonts share a family plan, a style with smaller solo ascenders can be pulled up toward the family driver. That’s intentional for a shared line box. --report quantifies it; --max-adjustment caps it; individual avoids it entirely.

Detection labels

Filename or measurement heuristics can mark fonts as script, decorative, unicase, or uniwidth. When a file is missed, force it with -a/--assume TYPE:PATTERN. The pictures use stand-in typefaces so the categories are visible. In the script and decorative pictures, the solid box is the shared line box and the dashed box is the clipping box. --exclude-measuring keeps a font out of the family math without classifying it.

The script keeps the family’s line box. The clipping box grows around the swashes, with extra room below.

The outline is taller than the text

Decorative

Illustrative and ornamental faces have a taller outline than the text styles. They keep the family’s line box. The clipping box grows around that outline, so it doesn’t pull the whole family taller.

-a decorative:"*Display*"

unicase

One letter height, one baseline

Hx Hx x-height

The unicase sits on the text face’s baseline, and its letter height lines up with that face’s x-height. It needs less room above the letters.

-a unicase:"*Unicase*"

uniwidth

Bold occupies the same width

Handgloves Handgloves

The weights already share their widths, so a weight change does not reflow the line. ebrium keeps that, and still gives the family one line box.

-a uniwidth:"*Headline*"

Superfamily

Families whose names share a prefix can be merged into one planning unit (superfamily). Use --exclude to keep a family out of that merge, and --merge / --ignore-term when names don’t group the way you want. Each --merge is one complete group: --merge "A,B" merges A and B, and -m A -m B does not.

Checkpoint

A cache file is written. Every measuring run, including -n and --report, writes .metrics_checkpoint.json in the current working directory. probe does not measure, so it does not write one.

The file caches measurements and clusters, and it resets when the options or the font set change.
