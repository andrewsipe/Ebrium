Vocabulary

Concepts

Terms you’ll see in the CLI, the report, and the planned metrics. Skim once; come back when a flag name stops making sense.

Cap height (optical)

The measured height of capital letters used as the anchor for the shared line box. Styles in one optical size should share that height. Measurement prefers the outlines over table values that may be stale.

Core and outliers

The core styles set one planned typo/hhea box. Effect cuts (Shadow, Extrude, Fine, and similar) and script companions inherit that box. Their outlines only widen Win. --no-cluster skips that plan and uses outline extremes for the line box instead.

Typo / hhea vs Win

A default run makes the line box at least 130% of the em — 1300 units when the em is 1000 — and sets the line gap to 0. Baseline to baseline is then 1300. The before picture is a file that has not been through that run. The letters stay the same size, and the em stays 1000.

  • sTypoAscender / sTypoDescender / sTypoLineGap (OS/2) and matching hhea values define the line box many apps use when USE_TYPO_METRICS is on (OS/2 v4+).
  • usWinAscent / usWinDescent are clipping bounds. Family-wide Win uses normalized extremes so nothing clips; decorative outliers can expand Win while still inheriting typo from the core cluster.
  • Line gaps are set to zero across typo and hhea.

Where the line box comes from

The default plan follows the Google Fonts vertical metrics pattern, which SIL’s line-metrics guide calls the recommended strategy and which Glyphs documents as the Google strategy:

  • Typo and hhea are the same numbers. That is the line box.
  • Both line gaps are 0. The box itself is the line spacing.
  • USE_TYPO_METRICS is on, so apps use that box instead of the Win values.
  • Win is the clipping box. It may be taller than the line box, and it is never shorter than the outlines it has to cover.
  • Styles in a family share one line box, so switching weight or italic does not change the line spacing of a paragraph.

Those guides set the line box by looking at the common letters and adjusting until the spacing looks right. ebrium replaces that step with a formula. The box starts at the measured cap height plus 25% of the em of headroom, with capitals centered in the box (ascender − cap = |descender|). If that span is under 130% of the em, it grows while staying centered. Measured clearance — tallest accented capital, deepest descender — can raise either side further; that is the only source of asymmetry. If clearance needs more than 130%, the span is allowed to exceed the floor and the run flags it. Win is the family’s outline extremes plus 2%, then raised again if the line box is taller. A script or decorative face can widen Win without pulling the family’s line box up to that extreme — the same idea as not letting one rare tall glyph set the spacing, done from the measurements instead of by hand.

The box is one set of numbers for the whole family, anchored on cap height. John Hudson’s note on Tamil and Latin and the SIL guide both point out that two scripts in one file often want different line spacing, and OpenType still stores a single set. ebrium does not add a second one.

Karsten Lücke’s font-metrics notes are the history behind the older rule that the typo span had to equal the em. That rule is no longer in the spec, and the default 130% floor does not follow it.

Letter height & top margin

--letter-height (default 130% of UPM) is a floor for the letter span — measured accented-cap or descender clearance may raise the box above it. --top-margin (default 25%) asks for headroom above capitals; it can be ignored when actual ascenders already clear it.

Shared box

A family run gives the core styles one line box. probe shows how far each file’s stored ascender would move to match it. --max-adjustment can cap that pull. individual plans each file alone.

Detection labels

Filename or measurement heuristics can mark fonts as script, decorative, unicase, or uniwidth. When a file is missed, force it with -a/--assume TYPE:PATTERN. The pictures use stand-in typefaces so the categories are visible. In the script and decorative pictures, the solid box is the shared line box and the dashed box is the clipping box. --exclude-measuring keeps a font out of the family math without classifying it.

The unicase sits on the text face’s baseline, and its letter height lines up with that face’s x-height. It needs less room above the letters.

-a unicase:"*Unicase*"

Superfamily

Families whose names share a prefix can be merged into one planning unit (superfamily). Use --exclude to keep a family out of that merge, and --merge / --ignore-term when names don’t group the way you want. Each --merge is one complete group: --merge "A,B" merges A and B, and -m A -m B does not.

Checkpoint

A cache file is written. Every measuring run, including -n, writes .metrics_checkpoint.json in the current working directory. probe does not write one.

The file caches measurements and clusters, and it resets when the options or the font set change.
