Vertical metrics, family-wide

ebrium normalizes typo, hhea, and Win metrics across a family so styles share a coherent line box and don’t clip — without touching unitsPerEm or outlines.

In place. By default fonts are overwritten with no backup. Preview with -n. Use probe to read metrics without writing. 
pipx install "git+https://github.com/andrewsipe/ebrium.git"
ebrium fonts/ -r -n

One command groups by family name.

  • ebrium fonts/ -r -n — one centered line box per family
  • --no-cluster — the same family, one box from the outline extremes so nothing clips
  • --match "Family A,Family B" — one box for family names that do not already group
  • ebrium probe — read-only

A run rewrites a variable font's default instance only and leaves MVAR and HVAR alone. probe reads that default instance and does not write.
