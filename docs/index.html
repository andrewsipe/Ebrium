Vertical metrics, family-wide

ebrium normalizes typo, hhea, and Win metrics across a family so styles share a coherent line box and don’t clip — without touching unitsPerEm or outlines.

In place. By default fonts are overwritten with no backup. Preview with -n or --report before writing. 
pipx install "git+https://github.com/andrewsipe/ebrium.git"
ebrium family /path/to/fonts -r -n

Pick a subcommand first — that choice is how fonts are grouped, and it decides which flags exist:

  • family — group by family name; cluster within each family (usual case)
  • individual — each font alone; no family pull
  • superfamily — merge families that share a name prefix
  • probe — read-only: does the line box already move, and do axis poles overflow a flat Win box?

Variable fonts: family, individual, and superfamily rewrite the default instance only. They leave MVAR and HVAR alone. probe reports two facts and does not write: a typo line box that already moves should be left, and a flat Win box is worth a later look only when some axis pole sticks out past the default ink.
